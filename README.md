# AI Interview Web

A modern AI-powered interview practice platform built with Django.

## Features

- AI-powered interview conversations
- Previous interview history
- User authentication (Login & Signup)
- Forgot password via email
- Modern ChatGPT-style interface
- Groq AI integration

## Tech Stack

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- Groq API

## Installation

```bash
git clone https://github.com/shivam0793-ai/AI_InterviewWeb.git
cd AI_InterviewWeb
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
